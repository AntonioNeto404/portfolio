## Sobre o projeto

Uma página estática, responsiva e acessível para apresentar trajetória profissional, stack técnica, projetos e canais de contato. O layout prioriza leitura rápida por recrutadores e destaca projetos com maior profundidade técnica.

## Funcionalidades

- Tema claro/escuro com persistência no navegador;
- Navegação responsiva com menu mobile;
- Scroll suave e destaque da seção atual;
- Animações de entrada com `IntersectionObserver`;
- Layout sem framework, com HTML semântico, CSS responsivo e JavaScript vanilla;
- Links diretos para projetos, GitHub, LinkedIn, e-mail e WhatsApp.

## Executar localmente

```bash
git clone https://github.com/AntonioNeto404/portfolio.git
cd portfolio
```

Abra `index.html` no navegador ou use uma extensão como Live Server no VS Code. O projeto não requer instalação de dependências.
